What actually changes

The method behind the view

The aim is not merely tidier names. The inventory must identify authoritative versions, permissions, the reason for retention, and the person authorised to approve a change. A later filename is not proof that a document is current.

01

Observe

Inventory every source file and the original path without modifying it.

02

Classify

Note uncertainty, duplicated versions, sensitive content and missing ownership.

03

Decide

Ask the accountable owner to confirm the authoritative record and treatment.

04

Verify

Reconcile every file, permission and link, then record the handover.

Evidence boundary

What this demonstrates

The exercise is fictional, but the judgement it tests is real: work from evidence, recognise risk and uncertainty, involve the actual owner, and verify the resulting records. This is not a claim that I reorganised these particular files for a client.
