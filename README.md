# Alan W. P. Gallagher — Personal Site

Static, multilingual (English/Irish) website for alanwpgallagher.info.

## Structure
- HTML pages in the repo root
- Shared assets in `assets/` (CSS, JS, images, documents)
- `sitemap.xml` and `robots.txt` included

## Notes
- English pages use `*.html`
- Irish pages use `*-ga.html`
- Language toggles link between pairs
