Draft workbench demo

Documentation control demo: reorganising an overgrown shared folder.

This draft page is being prepared for the Workbench. It is not linked from the live Workbench page yet.

The scenario is synthetic and public-safe. It shows a common operational problem: a shared file directory has grown organically over time. It still works for people who know it well, but it has become harder to maintain, review and hand over.

The demo will show how I would turn that messy working area into a clearer structure using a small project workbook, a task board, decision log, action log, risk log, rename map and handover note.

Problem

A working folder structure has become too dependent on memory.

Before

Files and folders have been added for immediate needs. Some are duplicated, some are unclear, some may be old, and some names only make sense to the people who created them.

Risk

The work continues, but the record is fragile. People may not know which folder is current, where the latest file sits, what should be archived, or how to hand the structure over safely.

Purpose

The workbook keeps the work visible. It records what exists, what will change, what has been decided, what risks need managing and what someone else would need to know afterwards.

Process

The demo will tell the story from messy folder to controlled structure.

Steps

  1. Inventory the current folder structure.
  2. Identify duplicates, unclear names and possible archive material.
  3. Design a simple target structure.
  4. Track rename and move decisions.
  5. Record actions, risks and checks.
  6. Create a short handover note.
